## Qt and PySide6

The desktop application uses Qt through PySide6, distributed under the GNU Lesser General
Public License v3 (LGPL-3.0). ELI Creation Station does not modify them. They are shipped as separate
library files in the installation folder so that a recipient can replace them with their
own build, as that licence requires; the installer must not prevent this. Source code for Qt
and PySide6 is available from the Qt Project (https://download.qt.io/ and
https://code.qt.io/). Anyone distributing ELI Creation Station must keep this notice and the licence
texts with it.

Only Qt modules offered under the LGPL are used: Qt Core, Qt GUI, Qt Widgets, Qt Network and
Qt Multimedia. Qt add-on modules that the Qt Project offers only under the GPL in its
open-source edition (Qt Charts, Qt Data Visualization, Qt Graphs, Qt Virtual Keyboard and
others) are excluded from every installer, and a test fails if the application imports one.

## FFmpeg (inside Qt Multimedia)

Sound and video are played and encoded by Qt Multimedia, which uses the FFmpeg libraries
(libavcodec, libavformat, libavutil, libswresample, libswscale) that the Qt Project builds
and ships with it, under the GNU Lesser General Public License v2.1 or later. That build
contains no GPL or non-free components. ELI Creation Station does not modify these libraries; they
are separate files in the installation folder that a recipient may replace. FFmpeg's source
code is available from https://ffmpeg.org/download.html (the version is printed by Qt
Multimedia when it starts) and Qt's build of it from https://code.qt.io/.

Video is encoded as H.264 only by an encoder the operating system or the graphics card
provides (Media Foundation on Windows, VideoToolbox on macOS, NVENC or VA-API on Linux),
licensed by its maker. Where none is present the video is written as MPEG-4 Part 2 with AAC
sound by FFmpeg's own encoders. Whether any patent applies to that fallback where a copy is
sold is a matter for the distributor's own advice. No GPL encoder (x264, x265) is shipped.

## Programs used if present, never shipped

Narration can use speech programs already installed on the buyer's computer: eSpeak NG
(GPL-3.0) and Piper (MIT; its voices each have their own licence) are run as separate
programs, and ELI v3's voices through ELI v3's own server. None of them is included in or
linked into ELI Creation Station. What a voice model speaks carries that voice's licence in its
manifest.

## What ELI Creation Station makes itself

Its procedural music, sound effects, images, templates and game designs are generated by
its own code: they contain no third-party samples, loops, stock images or fonts. Text drawn
into a picture or video uses the computer's own fonts.

## Models

ELI Creation Station ships no language model. A model you run on your own machine comes under its own
licence, which may restrict commercial or professional use. Check it before using it on a
project.
